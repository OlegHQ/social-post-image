# Swiss Content Generator

Generate Swiss-style LinkedIn post illustrations.

## Quick Start

```bash
# Install
pnpm install

# Run UI
pnpm dev

# Generate image via CLI
pnpm generate --preset vignelli-quote --quote "Your quote" --emphasis "Key phrase" --author "Name" -o poster.png
```

## Requirements

- Node.js >= 18
- pnpm >= 8
